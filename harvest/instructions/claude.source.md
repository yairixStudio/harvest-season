## Backlog — small tasks for later (the home is Clockwize)
Where something is recorded depends on where the folder lives. Before you record anything from a folder, ask which client and project it belongs to: `where_am_i` (Clockwize MCP) or `clockwize whereami <folder>`.

- **What you notice outside your task** (a missing test, cleanup, TODO, doc gap, dependency bump, a proposal, something the owner should decide): record it in Clockwize as an idea, not as a task and not in a file: `add_idea` (or `clockwize add-idea --client <id> [--project <id>] --title "<short>" --content "<what, where, why, what is open>" --kind idea|proposal --status awaiting_decision --source agent`). Don't do it now and don't drop it.
- **The user says "add to backlog" / "later" / "not now" / "תוסיף לבקלוג" / "לא עכשיו":** record a Clockwize task assigned to AI (`add_task`, then `hand_to_ai`), so Harvest pulls it by itself and runs it with leftover quota. A task tied to a time ("check this in a month", "next week", "בעוד חודש", "עד סוף החודש") gets that date as its day, in the user's words.
- **A folder with no home in Clockwize** (`where_am_i` says none or unknown, or the tool can't be reached): `BACKLOG.md` stays the place — record it with the `backlog` skill (`claude-harvest add ...`). In a folder that does belong to a client, `claude-harvest add` refuses and says so: record it in Clockwize.
- **Unattended** (scheduled task, headless `claude -p`, harvest agent): ideas only, never a task assigned to AI — agents never queue work for other agents. `claude-harvest` not found: run `~/.claude/harvest/bin/harvest.py` with the same arguments.

The Harvest Season widget in the menu bar pulls the tasks assigned to AI from Clockwize, runs them on separate `backlog/*` branches that are never pushed, and reports back there. Only the user approves proposals and merges branches (unless the owner switched on auto-merge for a project's tests, docs and lint changes).
